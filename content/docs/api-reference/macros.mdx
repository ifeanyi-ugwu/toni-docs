---
title: toni-macros
description: Reference for all procedural macros provided by the toni-macros crate.
---

All macros are re-exported through the `toni` crate — no direct `toni-macros` dependency is needed.

There are no `#[guard]` / `#[interceptor]` / `#[pipe]` / `#[middleware]` / `#[error_handler]` marker macros. Enhancer roles are detected from the trait impl: declare `#[injectable]`, implement `Guard<C>` / `Interceptor<C, R>` / `Pipe<C, R>` / `ErrorHandler<C, R>` / `Middleware`, list the type in `providers`, and apply it with `#[use_*]` or a factory `use_global_*` call.

## Module

### `#[module]`

**Target:** unit struct (`pub struct AppModule;`) or an impl block.

```rust
#[module(
    imports: [OtherModule, SeaOrmModule::for_root(url)],  // expressions — module types or DynamicModule calls
    controllers: [UsersController],                        // identifiers
    providers: [UserService, provide!("KEY", value)],      // identifiers or provider-macro calls
    exports: [UserService],                                // identifiers
    global: true,                                          // optional bool; exports visible everywhere
)]
pub struct AppModule;
```

All keys are optional. Modules pass directly to the factory: `ToniFactory::create(AppModule).await?`.

The impl form allows two kinds of methods:

- lifecycle hooks (`#[on_module_init]`, etc. — same signatures as on providers),
- `fn configure_middleware(&self, consumer: &mut MiddlewareConsumer)` for module-scoped middleware.

```rust
#[module(controllers: [UsersController], providers: [UserService])]
impl AppModule {
    #[on_module_init]
    async fn init(&self) -> toni::InitResult { Ok(()) }
}
```

## Providers and controllers

Providers, controllers, gateways, and RPC controllers all share one declaration shape: the attribute goes on the struct; handlers live in a separately-attributed impl block. The inline-struct forms (`#[controller("/p", pub struct X {...})]` etc.) are rejected with migration errors.

### `#[injectable]`

**Target:** struct.

```rust
#[injectable]                          // singleton (default)
#[injectable(scope = "request")]       // or "transient"
#[injectable(init = "create")]         // assemble via Self::create(...) — prefer #[new] instead
pub struct UserService {
    #[inject] repo: UserRepo,          // dependency, resolved by type
    #[inject("TOKEN")] key: String,    // dependency, resolved by custom token
    #[default(1000)] max: u32,         // owned state; untagged fields get Default::default()
}
```

Adds the `Clone` impl the container needs. Construction logic (`#[new]`) and lifecycle hooks live on the struct's plain `impl`.

### `#[inject]` / `#[default]` (field attributes)

- `#[inject]` — resolve by type (token is the fully qualified `type_name`).
- `#[inject("TOKEN")]` — resolve by custom token; also accepts a type or a `SCREAMING_SNAKE_CASE` const.
- `#[default(expr)]` — owned field initialized with `expr`.

A field cannot carry both `#[inject]` and `#[default]`.

### `#[new]`

**Target:** `fn name(deps…) -> Self` in the struct's impl. Not auto-detected — a bare `new()` without the attribute is ignored by DI.

Each parameter is resolved from the container (by type, or `#[inject("TOKEN")]` on the parameter), so a dependency can be a constructor argument without being a stored field.

```rust
#[injectable]
pub struct Server { port: u16 }

impl Server {
    #[new]
    fn new(config: ConfigService) -> Self {      // config injected, not stored
        Self { port: config.port() }
    }
}
```

### `#[controller]`

**Target:** struct. Same field rules as `#[injectable]`; `init = "…"` is rejected (use `#[new]`).

```rust
#[controller("/users")]                       // route prefix
#[controller("/users", scope = "request")]    // per-request controller instance
pub struct UsersController {
    #[inject] svc: UserService,
}
```

A controller with no `#[routes]` impl is valid and exposes no routes.

### `#[routes]`

**Target:** the controller's impl block. Scans HTTP-verb methods into routes; also hosts controller-level `#[use_*]` attributes (on the impl, not the struct).

```rust
#[routes]
impl UsersController {
    #[get("/")]
    async fn list(&self) -> impl IntoResponse { ... }

    #[post("/")]
    async fn create(&self, Json(dto): Json<CreateUserDto>) -> impl IntoResponse { ... }
}
```

## HTTP handler attributes

### Verb macros — `#[get]`, `#[post]`, `#[put]`, `#[delete]`

**Target:** methods in a `#[routes]` impl. The path argument is required; it is joined to the controller prefix (`"/users"` + `"/{id}"` → `"/users/{id}"`).

```rust
#[get("/{id}")]
async fn find(&self, Path(id): Path<i64>) -> impl IntoResponse { ... }
```

Handlers take extractors as parameters (`Path`, `Query`, `Json`, `Bytes`, `Body`, `BodyStream`, `Multipart`, `Validated`, or a whole `HttpRequest`) and return any `IntoResponse` type, or `Result<T: IntoResponse, E>` where `E` converts into `HttpError`.

These four are the exported verb macros. `PATCH`/`HEAD`/`OPTIONS` attributes are not currently exported by `toni-macros`.

### `#[sse]`

**Target:** method in a `#[routes]` impl. Declares a Server-Sent Events handler; always routes as GET.

The handler returns a stream of events, not a response:

```rust
// Infallible
#[sse("/events")]
async fn events(&self) -> impl Stream<Item = SseEvent> { ... }

// Per-event fallible
#[sse("/events")]
async fn events(&self) -> impl Stream<Item = Result<SseEvent, MyError>> { ... }
```

For setup that can fail before streaming starts, use a `#[get]` handler returning `Result<impl IntoResponse, E>` with an explicit `sse(stream)` call.

### `#[set_metadata]`

**Target:** handler methods, and the `#[routes]` / `#[subscriptions]` / `#[patterns]` / `#[grpc_methods]` impl block (applies to every handler in it). Takes one expression per attribute; repeatable. Attaches typed metadata, stored once at startup and read by enhancers via `ctx.metadata().and_then(|m| m.get::<T>())`.

Every declaration is kept: `get::<T>()` returns the most specific (the handler's over the impl block's), `get_all::<T>()` returns all of them, least-specific first. Works on all four transports; gRPC handlers cannot read it (their signature is the tonic trait's), but their guards, interceptors, and error handlers can.

```rust
#[derive(Clone)]
pub struct Roles(pub Vec<&'static str>);

#[set_metadata(Roles(vec!["admin"]))]
#[set_metadata(RateLimit { max: 100, window: 60 })]
#[get("/admin")]
async fn admin_panel(&self) -> impl IntoResponse { ... }
```

## Enhancer attributes

### `#[use_guards]`, `#[use_interceptors]`, `#[use_pipes]`, `#[use_error_handlers]`

**Target:** handler methods (method-level), or the `#[routes]` / `#[subscriptions]` / `#[patterns]` / `#[grpc_methods]` impl block (controller-level, applies to every handler in it).

Three argument forms, each repeatable and combinable:

```rust
#[use_guards(AuthGuard)]                      // type name — resolved from the DI container
#[use_guards(SimpleGuard{})]                  // struct literal — instantiated directly
#[use_guards(RoleGuard::new("admin"))]        // constructor call
```

Execution order: global → controller → method for guards/interceptors/pipes; method → controller → global for error handlers (most specific first). Interceptors run their after-phase in reverse order.

```rust
#[routes]
#[use_guards(AuthGuard)]                      // all routes in this controller
impl AdminController {
    #[use_interceptors(TimingInterceptor{})]  // this route only
    #[get("/stats")]
    async fn stats(&self) -> impl IntoResponse { ... }
}
```

### `#[catch]`

**Target:** free `async fn`. Lowers the function into a unit struct implementing `ErrorHandler<C, R>` that downcasts to `T` and returns `None` on no match (the chain advances).

```rust
#[catch(GuardRejection)]
async fn shape_rejection(err: &GuardRejection, _ctx: &HttpContext) -> HttpResponse {
    HttpResponse::forbidden()
        .json(serde_json::json!({ "denied_by_guard": err.guard_index }))
        .build()
}

// Apply like any error handler:
#[use_error_handlers(shape_rejection)]
```

The primary error path needs no `#[catch]` — a domain type implementing `toni::Error` renders automatically on every transport. Reach for `#[catch]` to reshape framework events or apply per-route custom rendering.

## Lifecycle hook attributes

**Target:** methods in a provider/controller impl or a `#[module]` impl block. All hooks must be `async fn`. Startup hooks on request/transient providers are a compile error.

| Attribute | Signature | Runs |
|---|---|---|
| `#[on_module_init]` | `async fn(&self) -> toni::InitResult` | after the DI container is built |
| `#[on_application_bootstrap]` | `async fn(&self) -> toni::InitResult` | after all modules init, before serving |
| `#[on_module_destroy]` | `async fn(&self)` | module teardown during shutdown |
| `#[before_application_shutdown]` | `async fn(&self, signal: Option<String>)` | before shutdown begins |
| `#[on_application_shutdown]` | `async fn(&self, signal: Option<String>)` | as the application shuts down |

Returning `Err` from a startup hook aborts startup with `StartupError::HookFailed`, naming the module and hook: `on_module_init` failures surface from `ToniFactory::create`, `on_application_bootstrap` failures from `app.bind()`.

## WebSocket gateway macros

### `#[websocket_gateway]`

**Target:** struct. Same field rules as `#[injectable]`. Implements `GatewayTrait`.

```rust
#[websocket_gateway]                                          // path defaults to "/"
#[websocket_gateway("/chat")]                                 // path
#[websocket_gateway("/chat", namespace = "lobby")]            // namespace
#[websocket_gateway("/chat", port = 3001)]                    // separate-port listener
pub struct ChatGateway {
    #[inject] broadcast: BroadcastService,
}
```

Without `port`, the gateway shares the HTTP listener (requires an HTTP adapter with WS upgrade support). With `port = N` (including `0`), it binds its own listener via the registered `WebSocketAdapter`. A bare `#[websocket_gateway]` with no `#[subscriptions]` and no hooks is a valid connection-only gateway.

### `#[subscriptions]`

**Target:** the gateway's impl block. Scans `#[subscribe_message]` methods into the event router; hosts gateway-level `#[use_*]` attributes. Not needed for connection hooks.

### `#[subscribe_message]`

**Target:** method in a `#[subscriptions]` impl.

```rust
#[subscribe_message("message")]
async fn on_message(&self, client: WsClient, msg: WsMessage) -> WsHandlerResult {
    Ok(WsMessage::text("echo").into())      // From<WsMessage> for WsHandlerOutput
}
```

Parameters are `FromContext<WsContext>` extractors, in any order and any subset (including none): `WsClient`, `WsMessage`, `Payload<T>` (the message deserialised), `Extensions`, `Session`, or `&WsContext` itself. The `(client, msg)` pair above is the common case, not the required signature.

Return `Ok(WsHandlerOutput::Empty)` for no reply, `::Single(msg)` (or `msg.into()`) for one, `::Stream(boxed)` for a push stream.

### `#[on_connect]`, `#[on_disconnect]`, `#[after_init]`

**Target:** individual methods in the gateway's impl (standalone single-method attributes, like `#[new]` — no `#[subscriptions]` required).

| Attribute | Signature | Notes |
|---|---|---|
| `#[on_connect]` | `async fn(&self)` \| `(&self, &WsClient)` \| `(&self, &WsClient, &WsContext)`, returning `Result<(), WsError>` | `Err` rejects the connection |
| `#[on_disconnect]` | same three shapes, no return value | |
| `#[after_init]` | `async fn(&self)` | once, after the path is registered |

A hook takes what it asks for, positionally. The trailing `&WsContext` is how a hook reaches the connection's session, which is not on the client.

## RPC controller macros

### `#[rpc_controller]`

**Target:** struct. Same field rules as `#[injectable]`. A dispatch target — declare it in the module's `controllers:` list, not `providers:` (WebSocket gateways stay in `providers:`). RPC has no connection hooks — `#[patterns]` is the only impl marker. A bare `#[rpc_controller]` with no `#[patterns]` is valid and routes nothing.

```rust
#[rpc_controller]
pub struct OrdersController {
    #[inject] svc: OrderService,
}
```

### `#[patterns]`

**Target:** the RPC controller's impl block. Scans `#[message_pattern]` / `#[event_pattern]` methods; hosts controller-level `#[use_*]` attributes.

### `#[message_pattern]` / `#[event_pattern]`

**Target:** methods in a `#[patterns]` impl.

- `#[message_pattern("p")]` — request-response; the return value is sent back.
- `#[event_pattern("p")]` — fire-and-forget; nothing is sent back.

```rust
#[patterns]
impl OrdersController {
    #[message_pattern("order.create")]
    async fn create(&self, data: RpcData, ctx: &RpcContext) -> Result<RpcData, RpcError> { ... }

    #[event_pattern("order.cancelled")]
    async fn on_cancelled(&self, data: RpcData, ctx: &RpcContext) -> Result<(), RpcError> { ... }
}
```

Parameters are `FromContext<RpcContext>` extractors, in any order and any subset (including none): `RpcData`, `Payload<T>`, `Extensions`, or `&RpcContext` itself. A parameter of any other type is the call's payload, deserialised into it via `RpcData::parse`; a `Serialize` return type is serialised via `from_serialize`. Errors may be any `toni::Error` type (auto-lifted to `RpcError::AppError` via `?`).

## gRPC service macros

### `#[grpc_service]`

**Target:** the service's inherent impl block, with the struct definition inline in the attribute (or a separate struct plus a `fn new(...)` constructor in the impl). A dispatch target — declare it in the module's `controllers:` list; the framework hands it to the gRPC adapter at bind time. A request-scoped service is built per call rather than once.

```rust
#[grpc_service(pub struct OrdersGrpcService {
    #[inject] repo: OrdersRepo,
})]
impl OrdersGrpcService {
    pub fn new(repo: OrdersRepo) -> Self { Self { repo } }
}
```

### `#[grpc_methods]`

**Target:** the `impl ProtoTrait for YourService` block (the tonic-generated service trait). Passes the impl through unchanged and emits the `GrpcServiceTrait` wiring that wraps the service in its tonic `*Server` and routes calls through the enhancer pipeline. `#[use_*]` attributes apply at the impl (service) or method level.

The `*Server` wrapper type is inferred from the trait name; override with `server = …`:

```rust
#[grpc_methods(server = orders_proto::OrdersServer)]
#[tonic::async_trait]
#[use_guards(AuthGuard)]
impl Orders for OrdersGrpcService {
    #[use_interceptors(LoggingInterceptor)]
    async fn create(&self, req: tonic::Request<CreateOrderRequest>)
        -> Result<tonic::Response<CreateOrderResponse>, tonic::Status> { ... }
}
```

## Derive macros

### `#[derive(toni::Error)]`

Derives the `toni::Error` trait. Tag the type — or each enum variant — with `#[error_kind(KIND)]`, where `KIND` is an `ErrorKind` variant: `BadRequest`, `Unauthorized`, `Forbidden`, `NotFound`, `Conflict`, `UnprocessableEntity`, `TooManyRequests`, `Timeout`, `Unavailable`, `Unimplemented`, `Internal`. Untagged variants fall back to a top-level `#[error_kind(...)]`, otherwise to `Internal`.

```rust
#[derive(Debug, thiserror::Error, toni::Error)]
enum BillingError {
    #[error("invoice {0} not found")]
    #[error_kind(NotFound)]
    InvoiceNotFound(String),

    #[error("card declined")]
    #[error_kind(UnprocessableEntity)]
    CardDeclined,
}
```

Handlers returning `Result<T, BillingError>` render the canonical envelope on every transport with no further code.

### `#[derive(Config)]`

Derives environment-variable loading for a config struct (used with `toni-config`'s `ConfigModule`). Field attributes are separate — `#[env]` and `#[default]` are never combined into one attribute:

```rust
#[derive(Clone, Config)]
pub struct AppConfig {
    #[env("PORT")]              // read from $PORT
    #[default(3000u16)]         // typed expression fallback when unset
    port: u16,

    database_url: String,       // no #[env] — defaults to SCREAMING_SNAKE_CASE of the field name

    #[nested]                   // load the field's type via its own Config derive
    redis: RedisConfig,
}
```

- `#[env("VAR")]` — source variable; defaults to the upper-cased field name.
- `#[default(expr)]` — typed expression used when the variable is unset. A set-but-unparseable variable is an error.
- `#[nested]` — delegate to the field type's own `Config` derive.
- Validation is gated on `#[validate(...)]` attributes: derive `validator::Validate` and mark fields, and values are checked at load time. No Cargo feature involved.

## Function-like provider macros

Used inside a module's `providers: [...]` list. Token position accepts a string literal (`"API_KEY"`), a type path (token becomes `type_name::<T>()`), or a `SCREAMING_SNAKE_CASE` const.

### `provider_value!`

```rust
provider_value!("APP_NAME", "ToniApp".to_string())
provider_value!(Duration, Duration::from_secs(60))     // type-based token
```

Registers a constant value.

### `provider_factory!`

```rust
provider_factory!("REQUEST_ID", || uuid::new_v4().to_string())
provider_factory!("APP_INFO", |config: ConfigService| build_info(config))   // typed params are injected
provider_factory!("STATUS", async |logger: LoggerService| check(logger).await)
```

Closure parameters are resolved from the container by type. Optional trailing arguments (comma-separated, any order): `scope = "request"` / `"transient"`, `lifecycle` (the produced value participates in lifecycle hooks — e.g. an `RpcClient` connecting at bootstrap), and a type hint naming the produced type.

### `provider_alias!`

```rust
provider_alias!("Config", ConfigService)    // new token → existing type-based provider
provider_alias!("APP_PORT", "PORT")         // new token → existing token
```

Both tokens resolve to the same instance.

### `provider_token!`

```rust
provider_token!("PRIMARY_CONFIG", ConfigService)
provider_token!(APP_GUARD, AuthGuard)       // const token
```

Registers the type under a custom token (instantiated via its own DI declaration).

### `provide!`

Unified macro with auto-detection — covers all the above:

```rust
provide!("API_KEY", "secret".to_string())               // value (auto-detected)
provide!("MAX_CONN", || 100_i32)                        // factory (auto-detected from closure)
provide!("LOGGER", |config: ConfigService| ...)         // factory with injected deps

// Explicit markers
provide!("EXPLICIT_VALUE", value("explicit".to_string()))
provide!("EXPLICIT_FACTORY", factory(|| build()))
provide!("CACHE_ALIAS", existing(CacheService))          // alias to existing provider
provide!("ALIAS", existing("TOKEN", ConcreteType))       // alias with explicit concrete type
provide!("PRIMARY_DB", provider(DatabaseService))        // type under custom token

// Multi-provider: several contributions under one token, collected into a Vec
provide!("PLUGINS", PluginA, multi(dyn Plugin + Send + Sync))
provide!("PLUGINS", PluginB, multi(Plugin))              // shorthand synthesizes dyn Plugin + Send + Sync
```
