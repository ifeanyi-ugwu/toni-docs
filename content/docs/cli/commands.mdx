The CLI has two commands: `toni new` and `toni generate resource`.

## toni new

Create a new Toni project from a starter template.

```bash
toni new <project-name>
```

The project name may contain only alphanumerics, `-`, and `_`. The command fails if a directory with that name already exists.

**Example:**

```bash
toni new my_api
# ✅ Successfully created project 'my_api'!
#
# Next steps:
#   cd my_api
#   cargo build
```

Generated layout:

```
my_api/
├── Cargo.toml
└── src/
    ├── main.rs
    └── app/
        ├── mod.rs
        ├── app.module.rs
        ├── app.controller.rs
        └── app.service.rs
```

`Cargo.toml` pins `toni = "0.2.0"`, `toni-axum = "0.1.0"`, and `tokio` with full features. The generated `main.rs`:

```rust
use app::app_module::AppModule;
use toni::ToniFactory;
use toni_axum::AxumAdapter;

mod app;

#[tokio::main]
async fn main() {
    let mut app = ToniFactory::new()
        .create_with(AppModule)
        .await;

    app.use_http_adapter(AxumAdapter::new(), 3000, "127.0.0.1")
        .unwrap();

    app.start().await.unwrap();
}
```

`AppController` serves `POST`/`GET`/`PUT`/`DELETE` at `http://127.0.0.1:3000/app`, each delegating to a matching `AppService` method. The dotted file names are mapped to Rust modules with `#[path]` attributes in `src/app/mod.rs` — see [Project Structure](/docs/getting-started/project-structure).

## toni generate resource

Generate a CRUD resource — module, controller, and service — and wire it into the application.

```bash
toni generate resource <name>
```

Run it from the project root (the command edits files under `src/app/`). `resource` is the only generator type; there are no separate `module`/`controller`/`service` generators.

**Example:**

```bash
toni generate resource users
```

Creates `src/app/users/`:

```
src/app/users/
├── mod.rs                  # #[path] declarations for the files below
├── users.module.rs         # UsersModule
├── users.controller.rs     # UsersController
└── users.service.rs        # UsersService
```

and wires it in automatically:

- `src/app/mod.rs` gains `#[path = "users/mod.rs"] pub mod users;`
- `src/app/app.module.rs` gains the import and `UsersModule` in its `imports:` list

Type names are the input name with the first letter uppercased (`users` → `UsersModule`, `UsersController`, `UsersService`); module and file names are snake_cased.

### Generated controller

```rust
use super::users_service::UsersService;
use toni::extractors::Path;
use toni::*;

#[controller("/users")]
pub struct UsersController {
    #[inject]
    users_service: UsersService,
}

#[routes]
impl UsersController {
    #[post("/")]
    fn create(&self) -> Body {
        Body::text(self.users_service.create())
    }

    #[get("/")]
    fn find_all(&self) -> Body {
        Body::text(self.users_service.find_all())
    }

    #[get("/{id}")]
    fn find_by_id(&self, Path(id): Path<String>) -> Body {
        Body::text(self.users_service.find_by_id(id))
    }

    #[put("/")]
    fn update(&self) -> Body {
        Body::text(self.users_service.update())
    }

    #[delete("/")]
    fn delete(&self) -> Body {
        Body::text(self.users_service.delete())
    }
}
```

### Generated service

```rust
use toni::*;

#[injectable]
pub struct UsersService;

impl UsersService {
    pub fn find_all(&self) -> String {
        "find_all".to_string()
    }

    pub fn find_by_id(&self, id: String) -> String {
        format!("find_by_id {}", id)
    }

    pub fn create(&self) -> String {
        "create".to_string()
    }

    pub fn update(&self) -> String {
        "update".to_string()
    }

    pub fn delete(&self) -> String {
        "delete".to_string()
    }
}
```

### Generated module

```rust
use toni::*;

use super::users_controller::UsersController;
use super::users_service::UsersService;

#[module(
  imports: [],
  controllers: [UsersController],
  providers: [UsersService],
  exports: []
)]
impl UsersModule {}
```

The stub methods return placeholder strings — replace them with real logic and typed responses (see [Quick Start](/docs/getting-started/quick-start)).
