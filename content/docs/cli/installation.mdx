---
title: CLI Installation
description: Install the Toni CLI to scaffold new projects and generate resources.
---

The Toni CLI (`toni-cli`) scaffolds new projects and generates CRUD resources (module + controller + service, wired in automatically) from the terminal.

## Install

```bash
cargo install toni-cli
```

Verify installation — the version printed matches the installed crate version:

```bash
toni --version
# toni 0.1.2
```

## Updating

```bash
cargo install toni-cli --force
```

## Requirements

- Rust 1.85 or later (the CLI and generated projects use the 2024 edition)
- Cargo on your PATH
