---
title: Configuration
description: Typed configuration loaded from the environment or a file, and validated before the application starts.
---

Configuration is a struct you derive `Config` on. Fields map to environment variables or file keys, defaults are declared inline, and the whole thing is injected as `ConfigService<T>` — so a typo in a variable name is a startup failure rather than a `None` discovered in production.
