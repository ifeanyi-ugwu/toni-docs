---
title: Database
description: Six integrations, each registering a connection handle you inject by type.
---

Every integration follows the same shape: call `for_root` once in the root module, then inject the driver's own handle — `DatabaseConnection`, `Pool<Postgres>`, `Database` — wherever it is needed. Toni does not wrap the driver, so the query API is the one the driver's own documentation describes.

Five of the six run a reachability probe at startup and fail `create` with a redacted error rather than deferring the failure to the first query. Prisma is the exception, and its page says why.
