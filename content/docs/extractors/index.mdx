---
title: Extractors
description: Typed request data as handler parameters, checked at compile time.
---

An extractor is a handler parameter whose type says what to pull out of the request. `Path<u32>` parses a route segment, `Json<T>` deserializes a body, `Multipart` streams an upload. Extraction failures answer with a 400 before the handler runs, so a handler body never validates its own inputs.

One rule governs the whole chapter: a request has one body, and only one extractor may read it. That is checked at compile time for the built-in extractors, and both offending parameters are named in the error.
