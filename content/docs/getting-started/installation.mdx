## Prerequisites

- Rust 1.85 or later (the crates use the 2024 edition)
- Cargo

## Option A — Start from a template with the CLI

The fastest way to get a working Toni project is through the CLI:

```bash
cargo install toni-cli
toni new my_app
cd my_app
cargo run
```

This scaffolds a project with `AppModule`, `AppController`, and `AppService` wired together and ready to run. See [CLI Commands](/docs/cli/commands) for the exact layout it generates.

## Option B — Add to an existing project

Add the core crate and your chosen HTTP adapter to `Cargo.toml`:

```toml
[dependencies]
toni = "0.2"

# Choose one adapter:
toni-axum = "0.1"     # Axum + Tokio  (I/O-bound workloads)
# toni-actix = "0.1"  # Actix-web     (CPU-bound workloads)
# toni-salvo = "0.1"  # Salvo
# toni-poem = "0.1"   # Poem
# toni-rocket = "0.1" # Rocket

# Async runtime (required with toni-axum)
tokio = { version = "1", features = ["full"] }

# Serialization (nearly always needed)
serde = { version = "1", features = ["derive"] }
serde_json = "1"
```

The `toni` crate's default `logger` feature installs a `tracing` subscriber at startup, so applications log to stderr with no setup — `default-features = false` compiles it out. See [Logging](/docs/techniques/logging).

### Optional crates

| Crate | Purpose |
|-------|---------|
| `toni-config` | Environment-based configuration with optional validation |
| `toni-async-graphql` | GraphQL via `async-graphql` |
| `toni-juniper` | GraphQL via `juniper` |

## Minimum working main

```rust
use toni::ToniFactory;
use toni_axum::AxumAdapter;

#[tokio::main]
async fn main() {
    let mut app = ToniFactory::create(AppModule).await;
    app.use_http_adapter(AxumAdapter::new(), ("127.0.0.1", 3000)).unwrap();
    app.start().await.unwrap();
}
```

That's it. Everything else — modules, controllers, services — lives in your application code and gets wired together by the DI container at startup.

<Bridge>
Coming from NestJS? The rough translation is:

```ts
// NestJS
const app = await NestFactory.create(AppModule);
await app.listen(3000);
```

```rust
// Toni
let mut app = ToniFactory::create(AppModule).await;
app.use_http_adapter(AxumAdapter::new(), ("127.0.0.1", 3000)).unwrap();
app.start().await.unwrap();
```

`ToniFactory::create` takes the root module directly, like `NestFactory.create`. The adapter is wired separately via `use_http_adapter`, which registers all routes from the module tree. No `app.init()` call is needed — the DI container is built during `create`; `start()` binds the socket and serves until shutdown.
</Bridge>
